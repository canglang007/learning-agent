# 内测试用问卷（可直接发给同学）

> 用途：收集首批真实试用反馈，用于修 bug 和判断功能优先级。
> 目标：8–12 题，5 分钟填完，不要求写长文。

## 一、给体验者的话（复制到问卷开头或聊天里）

```
我在做一个学习助手：上传讲义、论文、课程视频，它会自己翻页看图、翻视频找片段，
然后给答案并把引用跳到原文那一页（或那个时间点）。

现在是内测，想请你随便用用，真实感受就行，骂也行。

几句实话先说清楚：
- 服务器很小（1 核 1G），慢是正常的，卡住请告诉我时间点。
- 所有访客共用一个资料空间，别传私人文件、真作业、简历。
- 你建的会话别人也能看到（没有账号体系）。
- 检索用的是轻量版，正式版会更强。

链接：http://20.205.19.150:8320
口令：GdrXWV3HCE4N
```

## 二、问卷题目

**1. 你的身份**
- 本科生 / 硕士生 / 博士生 / 已工作 / 其他

**2. 你用什么设备打开**
- 电脑浏览器 / 手机 / 平板 / 都试了

**3. 从点开链接到看见页面，顺畅吗**
- 很顺（几秒就好）/ 有点慢但能等 / 卡了很久 / 打不开

**4. 你成功问出并获得回答了吗**
- 问了，拿到答案 / 问了，但一直转圈/报错 / 没试

**5. 有没有试过点开答案里的引用（跳到那一页 / 那个视频片段）**
- 试了，跳对了 / 跳了但位置不准 / 没找到引用 / 没用这个功能

**6. 这份答案真的解决了你的问题吗（1–5 分）**
- 1 完全没用 → 5 直接可用

**7. 答案里的「在图里看到了什么」有没有用（如果答案带图或公式/表格）**
- 有用，省了我翻页 / 一般 / 好像看错了 / 没遇到这种题

**8. 上传你自己的资料试了吗（PPT/PDF/视频）**
- 传了，能问 / 传了，但处理失败或很慢 / 没传（如果可以，说下原因）

**9. 最想先补哪个功能（可多选）**
- 处理更快
- 答案更准、更少胡编
- 支持更多格式（手写、扫描件、长视频）
- 多轮追问、能记住我前面问过什么
- 帮我出题 / 划重点 / 做复习计划
- 其他（写一句）

**10. 卡住或报错的地方（越具体越好）**
- 时间点 + 你点了什么 + 屏幕上出现了什么

**11. 如果明天还能用，你会拿它干什么**
- 开放式，一两句

**12. 会推荐给同学吗（0–10）**
- 0 不会 → 10 一定推荐

## 三、回收后怎么用

- 故障类（第 3/4/8/10 题）：直接对日志时间点定位，按 `docs/deploy.md` 看服务状态。
- 质量类（第 6/7 题）：低分样本走 A 档挖掘 `python -m learning_agent.evaluation mine-feedback`，人工确认后进 B 档队列。
- 需求类（第 9/11 题）：只统计频次，不按单人诉求改路线。
