# 公开边界与分享清单

更新于：2026-11-17 21:45:00（Asia/Shanghai，UTC+08:00）。

Learning Agent 默认是**本机单用户**项目。设置 `LA_ACCESS_TOKEN` 后可以变成一个**共享口令的小型演示实例**：页面和接口都要求先输口令，登录失败按来源 IP 限流，会话按浏览器隔离。它仍然不是可以直接对外运营的在线服务。

## 当前不提供

- 账户体系、注册、密码找回和权限管理；口令所有人共用；
- 调用配额、账单上限和防滥用；限流只在进程内存里，重启即清零；
- 多租户隔离：资料空间仍是共用的，会话隔离只按浏览器 cookie；
- 内置 https、审计日志、对象存储和公网运维；
- 对上传资料、模型费用或第三方服务日志的托管保证。

## 公开代码仓库前

1. 确认 `.env`、`data/`、`notes/`、`experiments/`、`output/` 和数据库没有被跟踪。
2. 运行：

   ```bash
   uv run python scripts/check_public.py
   ```

3. 检查 README、Issue 模板、截图和文档里没有密钥、私人资料或可识别对话。
4. 确认仓库可见性与预期一致；本项目不会自动把私有仓库改成公开。
5. 保留 [SECURITY.md](../SECURITY.md) 的私密报告渠道说明。

## 分享演示时

- 公开分享时使用固定的合成演示数据，或你有权公开的课程素材；不要把私人课程视频、讲义或转写上传到公开仓库。
- 本地演示可以使用本地真实课程 PDF/视频（见[真实课程多模态演示](demo.md)），但演示结束后不要公开素材、会话数据库或截图中的课程内容。
- 如果部署到公网，必须在反向代理层加访问控制、限流和额度；不要只依赖应用内约束。
- 使用独立、低额度的模型 key；不要复用个人主账号的长期 key。
- 明确标注“本机单用户项目 / 演示实例”，不要把演示回答说成教学效果。
- 收集反馈前先给参与者说明任务、时长、隐私和退出方式。

## 模型费用与数据

- 提问、摘要、向量和转写可能产生第三方费用；项目不提供费用上限保证。
- 发送给模型服务的内容包括选中的资料片段、字幕和图像；上传前确认你有权处理这些资料。
- 本地 `data/` 和 `notes/` 不随仓库分发；共享截图或日志前先脱敏。
