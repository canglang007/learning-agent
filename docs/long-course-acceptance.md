# 完整课程导入与恢复验收

更新于：2026-10-20 14:59（Asia/Shanghai，UTC+08:00）。

本次解决长课程超过原100 MB/60分钟限制，以及ASR中断后丢失中间结果的问题。默认媒体上限现为2 GiB、4小时（超过4K自动缩到1280宽，不再要求用户先转码）；上传按块落盘，转写按时间窗口读取并逐片保存。统一启动器、首次向导与真人学习效果评估不属于本次完成内容。

中文完整课使用已有公开字幕，**没有将整课中文ASR列为通过项**。两份资料均为实际H.264/yuv420p/AAC MP4，可直接回放原文件；其他格式的转码路径通过真实小媒体测试，未逐一实测四小时转码。2 GiB/4小时是配置与校验上限，最大实测文件为上述英文课。

原始媒体、完整字幕、数据库和验收结果均保存在被忽略的`data/`，不分发到仓库。

## 恢复与时间轴

英文课采用300秒核心区间、两端最多5秒上下文，共18片。保存前两片后SIGKILL处理进程；重启后从未保存片段继续。前两片保留`created_attempt=1`，其余片段为第二次执行，完整任务成功。

实际检查了300、2100、3600和5100秒附近的结果。3600秒之后仍使用完整原文件时间，3700–3730秒可读取两门课的字幕；回放Range请求返回206。浏览器还验证长课播放器及上传暂停、刷新后重新选原文件、明确确认续传的流程。

原始分片合并发现2100秒处存在“整句/句尾”两种分段造成的重复，完全相等去重没有覆盖。修复后，仅跨片、时间重叠且文字完全相同，或令牌严格包含且时间区间也包含的片段去重；不同措辞及不同时间的实际重复保留，另存去重说明。用已保存的18片重新合并后去除1个重复片段，得到1876段字幕，没有再次运行ASR。对应回归测试覆盖相同时间内不同措辞和之后正常重复的保留。

中文60分钟样本可与公开字幕在同一位置对照，但Whisper base将“程式”错识别成“城市”、将英文术语function错识别成“方向”。这是识别内容错误，不能靠时间换算修复。因此已有字幕优先，不将时间范围合法等同于文字正确，也不宣称逐词精准或已完成独立人工听写评估。

## 资源观察

本机CPU/int8、Whisper base；API验收驱动与转写进程分开。另截取同一英文课的约30分钟版本，用相同分片配置处理。

| 输入 | API验收驱动峰值RSS | 转写进程采样峰值RSS |
|---|---:|---:|
| 约30分钟 | 87.0 MiB | 1050.4 MiB |
| 约87分钟 | 88.4 MiB | 1225.9 MiB |

API驱动使用`getrusage`，处理进程每2秒采样；后者可能漏掉短暂峰值。完整英文转写及一次中断恢复约339秒，仅供本次机器/模型样本参考；两次试验不是严格隔离的速度基准。内存中没有整课波形，进程占用还包括模型、解码器及其分配器，不承诺固定RAM或固定处理速度。本次未调用聊天或云端转写API。

## 可复现入口

准备好本机媒体与字幕后运行（会进行本地模型计算；模型未缓存时可能需要下载）：

```bash
uv run python examples/evaluate_long_course.py /path/to/english-course.mp4 \
  --chinese /path/to/chinese-course.mp4 --captions /path/to/chinese.vtt \
  --output data/evaluations/long-courses-local
```

脚本通过项目API上传、发布任务，并启动实际处理子进程，在成功保存两个分片后强制终止再恢复。输出资料信息、分片执行次数、资源采样及后半节观察到指定目录。工程结果与内容复核分开，不能据此生成教学效果通过率。单独用`--import-only`可验证上传而不运行ASR。

当前恢复依赖同一本机数据目录。浏览器刷新需要重新选择同一文件并确认，文件名/大小/修改时间不证明内容相同；本阶段没有全文件去重。转码中断重做该阶段，不能任意帧续算；旧整段ASR任务不混入新分片方案。ASR边界仍可能断句、漏词和错词，兼容云端ASR只有协议测试、尚未真实服务验收。云端未保存的当前片段重试可能再次计费。
