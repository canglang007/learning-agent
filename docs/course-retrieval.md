# 长课程导航与检索验收

本阶段把问题从“指定页/短片段讲解”推进到“用户不知道答案位置时，找到证据并讲清楚”。解释质量和定位质量分别检查；检索命中不能代替讲解正确性。

## 实现

统一段落保留资料ID、顺序、PDF物理页/页内行号、文字行号、字幕起止时间及来源映射。PDF文字按页内长度分段，不跨页；文字优先保留标题边界；相邻字幕按45秒、文字长度或停顿分组。超长单行或字幕再按文字长度拆分，保留原位置；单条字幕的时间只代表原字幕范围，不声称能定位其中每个词。

SQLite持久保存段落、索引版本与向量。既有资料可延迟补建；替换字幕或修改来源时，在同一事务中使旧段落和向量失效。新段落ID不复用旧版本，Agent拿到旧ID需重新搜索。网络推理在数据库事务外执行。

BM25使用英文词和中文二元词，参数 `k1=1.2, b=0.75`；不靠原始字符串子串评分。语义分支用归一化向量的精确余弦相似度。本轮使用本地Ollama的bge-m3密集向量，没有使用该模型的稀疏/ColBERT输出。两个分支各取前30项，以 `sum(1/(60+rank))` 融合，不直接相加BM25和余弦原始分数。返回前5项，同一PDF页最多2段，保留各分支名次用于解释排名来源。

方法与接口参考：[BM25教材](https://nlp.stanford.edu/IR-book/html/htmledition/okapi-bm25-a-non-binary-model-1.html)、[RRF说明与公式](https://www.elastic.co/docs/reference/elasticsearch/rest-apis/reciprocal-rank-fusion)、[Ollama批量向量接口](https://docs.ollama.com/api/embed)、[BGE-M3模型说明](https://huggingface.co/BAAI/bge-m3)。这些文献描述方法，不代表本项目已经取得文献中的效果。

Agent可自主调用：

- `search_materials`：搜索全空间，或限定某份资料；可改写中英文查询交叉核对。
- `material_outline`：分页浏览PDF页面首行、文字段落或5分钟媒体分组；图片页/缺字幕时间组保留入口。
- `read_context`：按命中段落读取前后最多各2段，再决定是否阅读整页、看图或查看视频。
- 原有阅读/视觉工具继续使用，没有强制每轮先检索或固定重试次数。

来源映射中的时间是当前文件在原视频中的起点。播放器、媒体工具参数、正文引用使用当前文件时间；工具另给原视频时间。导航摘要不作为已读证据，读取的实际段落可支持相应位置引用，但不代表看过页面图像。

## 对比设置

固定问题和参考位置放在 `examples/suites/course_retrieval.json`。参考位置和评分要点不会发送给模型。12条检索问题中10条有证据，另2条检查“相近主题不等于可回答”；后两条不计入命中率。命中位置只是一种粗粒度相关性代理，不是完整的人工逐段标注。部分题预设参考位置仅含PDF，返回同概念的真实视频片段可能仍未计分；因此该指标称为“预设参考位置命中”，未命中不直接判为无相关证据。视频相关性另作内容复核。

语料为两份完整讲义（68页、96页），以及CS336前45分钟和中文课程原视频第45–75分钟。片段是连续长区间，未按每道题的答案切成小窗口。原视频保存在本机，来源与下载方式沿用[第一阶段资料说明](learning-evaluation.md)。英文视频使用本地Whisper base转写；中文视频使用课程公开繁体中文字幕，对截取区间裁剪并减去2700秒。它们不是同一转写质量条件，不据此比较中英文ASR优劣。

三种检索设置使用相同问题、同一资料空间：

| 设置 | 用途 |
|---|---|
| lexical_baseline | 之前的词重合计数，PDF/文字12行、媒体逐字幕 |
| bm25 | 新统一段落上的词法排序，用于区分分段与排序变化 |
| hybrid | 同一套新段落上的BM25与密集向量RRF |

检索指标为有证据题的Hit@5和MRR@5；记录每题实际返回模式、候选、各分支名次、耗时。2条无证据题可以返回相关候选，不能用相似度阈值自动声称答案存在。

讲解对照为3组×2回合，在旧词法与hybrid设置分别运行，共12回合。覆盖计算量/时间与精确测量不足、残差结构与数值例子、工具执行与错误观测。模型可以自主改写查询和补查；因此最终讲解对比不等同于单次检索对比。保留全部回答、调用、usage和延迟，对照课件/字幕复核，不宣称真人学习收益或独立评审通过率。

## 复现

原视频可以在本机截取，当前应用仍限制单份媒体100 MB、60分钟：

```bash
ffmpeg -i data/acceptance/real-courses/cs336-original.mp4 -t 2700 \
  -vf 'scale=-2:480' -c:v libx264 -preset veryfast -crf 28 \
  -c:a aac -b:a 48k -movflags +faststart data/acceptance/real-courses/cs336-first45min.mp4
ffmpeg -ss 2700 -i data/acceptance/real-courses/ntu-original.mp4 -t 1800 \
  -vf 'scale=-2:480' -c:v libx264 -preset veryfast -crf 28 \
  -c:a aac -b:a 48k -movflags +faststart data/acceptance/real-courses/ntu-45to75min.mp4
```

中文区间字幕需自行从公开原字幕裁剪到2700–4500秒并减去2700秒，保存为suite指定的VTT。使用自有资料时可修改suite路径与来源；真实资料和原始结果不随代码分发。

```bash
# .env配置讲解API、本地ASR，以及已验证的向量服务
uv run python examples/evaluate_retrieval.py examples/suites/course_retrieval.json \
  --output data/evaluations/course-retrieval-v1 --prepare-only
# 等上一步结束后运行：仅比较检索，不调用讲解API
uv run python examples/evaluate_retrieval.py examples/suites/course_retrieval.json \
  --output data/evaluations/course-retrieval-v1
# 增加12回合真实模型对照，会产生讲解费用
uv run python examples/evaluate_retrieval.py examples/suites/course_retrieval.json \
  --output data/evaluations/course-retrieval-v1 --agent
```

同一输出目录复用已完成资料与索引；已记录的讲解组不会重复扣费。中断组保留已完成回合，需另建实验目录重新运行。不要并发准备同一工作区。改变问题、语料或实现时保留原始报告并使用新目录。

## 范围

精确向量扫描与本地SQLite针对小型课程空间，尚未进行大语料吞吐验证；没有引入向量数据库服务、重排器、自动语义分章或长期学习记忆。索引准备是单进程后台任务，重启后可复用已完成批次并重新准备；任务状态不冒充持久队列。专业术语ASR误识别、跨语言失败、图文之间的证据缺口仍需通过检索改写、补读和视觉核对处理。

## 本轮结果（2026-10-19）

本机276个段落使用bge-m3的1024维密集向量，首次完整构建约9.02秒。以下为单次固定套件运行，不是统计显著性结论：

| 检索设置 | 预设位置Hit@5（10题） | MRR@5 | 12条查询中位耗时 |
|---|---:|---:|---:|
| 旧词法 | 30% | 0.200 | 32.5 ms |
| BM25 | 40% | 0.245 | 9.0 ms |
| BM25+向量RRF | 70% | 0.470 | 109.5 ms |

三种设置均未向检索器提供答案位置。两条资料不足题不计入命中率；三种方式都会返回主题相近候选，不能据此推断资料足以回答。RRF查询包含本地向量接口耗时，索引准备另计；未推测第三方服务的费用单价。

需要保留的局限：中文提问查英文课件的旋转位置编码仍未命中预设页；带课程名的查询可能把课程封面推高；前五名也可能被另一门课程的中英文词面干扰。计算量/耗时和门控两题虽未命中预设PDF位置，视频候选实际包含相应概念，因此这些不能直接叫作完全检索失败。没有为了这组结果调阈值、改问题或增添答案关键词。

讲解对照允许模型先列目录、限定资料并改写查询，所以旧词法后端也可能被Agent补救。对照使用相同工具集，只替换检索后端；不能把首查命中率的提升自动说成最终讲解正确率的提升。原始明细在本机 `data/evaluations/course-retrieval-v1/`，不发布课程文件或用户私有记录。

12回合对照全部执行完成；执行Agent对照公式、图像、字幕与工具观察复核，未发现严重数学或图表错误。该结果不是独立人工评分，回答偏长仍然存在。

| 讲解后端（各6回合） | 工具调用总数 | 中位响应时间 | 输入/输出tokens | 可解析位置引用 |
|---|---:|---:|---:|---:|
| 旧词法 | 27 | 44.20 s | 169,990 / 9,033 | 17/17 |
| hybrid | 22 | 40.80 s | 165,215 / 8,727 | 18/18 |

两组均主动限定资料、改写查询，并实际核对PDF/视频；hybrid组在中文工具执行题中自主使用了 `read_context` 补读前后段。两组都拒绝了无数据支持的A100精确毫秒差，正确区分了pre/post-norm数值例子和100/10000度工具错误示例。工具错误均为0；35个引用的位置可解析不代表每句话都得到独立语义验证。

单次对照中调用数量与延迟有所下降，不能排除模型采样和回答长度的影响；不据此宣传稳定节省比例或普遍教学提升。usage是服务返回的原始tokens累计，未按未知网关单价换算金额。34项工程测试通过，网页目录跳页、索引准备及来源偏移保存/重启恢复另有实际检查。
