# 3–5 分钟真实演示

更新于：2026-11-01 12:55:00（Asia/Shanghai，UTC+08:00）。

这套演示使用**合成数据**，不依赖私有课程文件，也不会在准备阶段调用模型。提问会产生模型费用。

## 准备

```bash
uv sync --extra dev
uv run python examples/prepare_demo.py --output data/demo-public
./start.sh --data-root data/demo-public
```

打开 <http://127.0.0.1:8320>。Docker 用户见 README 的 Docker 段落。

## 演示顺序

### 0:00–0:40 打开与定位

- 展示资料空间“演示课程”：`matrix-notes.md` 和 `matrix-worksheet.pdf`。
- 说明这是合成演示数据，不是真实课程；目标是“讲懂 + 可回查”，不是固定检索流程。
- 新建会话，指出空会话的三个示例问题。

### 0:40–2:00 第一次提问

> 请解释 C[1,2] 的计算，并告诉我资料里哪一页支持这个结论。

观察并讲解：

- 任务卡显示模型请求、工具开始/返回，而不是百分比动画；
- Agent 自主调用资料工具，实际读取 PDF 第 1 页；
- 回答给出 `C[1,2] = 1×0 + 2×1 + 3×0 = 2`，并引用 `matrix-worksheet.pdf:p1`；
- 点击“查看 matrix-worksheet.pdf 第1页”，阅读器打开页面图像，证明来源可回跳。

### 2:00–3:30 反馈与换讲法

- 点击“换个例子”，确认发送。
- Agent 用同一组自构矩阵分别计算 1-based 与 0-based 的 `C[1,2]`，结果为 24 和 61。
- 说明：反馈绑定到上一条回答；“换个例子”不是重新检索一遍原文。

### 3:30–4:30 评测页

- 打开 `/evaluation`。
- 展示实验摘要：计划回合、状态、主模型调用、Token、复核状态；原始 JSON 收在“开发者详情”。
- 说明执行完成、回答质量、学习收益是不同维度；待复核不当作通过。

### 4:30–5:00 边界

- 本机单用户；公开代码仓库不等于公网服务；没有账户、租户隔离和内置限流。
- 不宣称真人学习收益或“用户规模”；公开演示需要固定的合成数据、低额度 key 和外部限流。
- 详细边界见 [公开边界](public-boundary.md)。

## 现场失败预案

- 没有配置模型：页面显示“未配置模型”，可先浏览已有会话；配置后再提问。
- 模型/网络不可用：明确说明是外部服务问题，展示已有会话和评测报告，不把历史回答伪装成现场生成。
- 端口被占用：换 `--port`，不要结束已有服务。
- 音视频演示：需要 ffmpeg/ffprobe；本套合成 demo 不依赖音视频。
