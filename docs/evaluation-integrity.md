# 评测完整性：结论服从事实

更新于：2026-11-23 20:10:00（Asia/Shanghai，UTC+08:00）。

这不是一篇通用的科研伦理说明。它记录本项目真实发生过的一次事故，以及由此定下的
改动纪律。写下来的目的很具体：让下一个人（或者下一个 agent）在遇到"结论要撑不住了"
的那一刻，有东西能拦住他。

## 事故：为了让旧结论成立而把材料塞回语料（2026-11-23）

背景：检索语料从"两三分钟切片 + 5 份材料"换成两讲整讲原片后，语料变成 6 份材料
（`docs/multimodal-eval.md`）。旧文档里有一句"两份材料无法经文字检索"——一份是纯图
`worksheet.pdf`，另一份原本是无声视频 `cs336-prenorm-silent.mp4`。换语料时那个无声
视频已经被移出去，于是这句话只剩一例能撑住。

我做的事：把它重新塞回检索语料，并在构建脚本里加注释"为了让『两份材料无法经文字
检索』的结论继续成立"。

为什么这是错的，说清楚三点：

1. **它对实验零贡献。** 那份材料在检索集里 0 个分块、0 条题，塞回去指标一个字都不变
   （删掉之后所有数字确实没变）。也就是说，这个改动的唯一效果是让一句旧文档读起来
   还成立——它改善的是叙事，不是事实。
2. **它把"结论不被推翻"当成了目标。** 真实目标只有一个：结论更接近事实。"两份材料
   不可文字检索"这句话如果只剩一例，正确的反应是改写这句话，而不是去凑第二例。
3. **它是偷懒的自我安慰，不是精心设计的造假。** 这也是它危险的地方：没有任何一步
   看起来像作弊，每一步都很"顺手"。

处置：删除该材料；脚本开头改成"语料只放被题目用到的材料"；文档改为"只有
`worksheet.pdf` 不可文字检索；无声视频属能力用例 `silent_video`，走 `bindings`"。

## 判定规则：改语料、改标注、改计分口径之前，先做四次自问

1. **反向检验。** 如果这个结论反过来，我还会做同样的改动吗？如果不会，那就是操纵。
2. **依据来源。** 改动的理由必须能指向材料自身的客观属性——页数、文字层有没有、
   时长、字幕有没有、区间是否跨块。指向"某个数字会变好看"或"某个旧说法会成立"的，
   一律不成立。
3. **零贡献检验。** 这个改动会让指标变化吗？如果不会，那它是为了什么？只可能为了
   叙事。（这条是本项目这次事故最锋利的探针。）
4. **分母纪律。** 把题标成不计分，必须有材料层面的客观理由，**并且**写明谁来接管它
   （哪个能力用例覆盖）。不允许难题靠"不计分"消失。

## 什么算正常调整，什么算迎合结论

正常调整：

- 材料客观属性标错了（页数错、字幕段数错、标注区间跨块）——修，并记录修的依据。
- 标注过窄或过宽——复核后按证据改，改完在文档里写清为什么；不许只挑对自己有利的题改。
- 研究问题变大导致语料扩张（如 17 题 → 83 题）——允许，但必须在换之前就声明
  "旧数字作废、不可比"，而不是换完再解释。历次口径与旧数字统一记在[检索口径沿革](retrieval-history.md)。

迎合结论（禁止）：

- 为保住某个结论增删材料。
- 只对被质疑的那几题放宽标注（选择性放宽）。
- 改分母让比例好看。
- 用"样本小"当挡箭牌，回避本来能做的大样本复核。

## 披露义务

- 任何语料、标注、计分口径的改动，commit message 写动机与依据，别只写"更新数据"。
- 新旧结果不可比时，在文档里明写"旧数字作废"，不要并列摆放让人误读。
- 结论变差时，顺序是先记录、再分析、最后才谈改进；顺序不许倒过来。

## 机器能挡住的那一小部分

`scripts/check_evaluation.py`（CI 里跑，不调模型）现在会拒绝：

- 检索集里标了 `unretrievable` 却没写 `reason` 或 `readable_by` 的题——不许有无人
  接管的豁免；
- `reason` 里出现意图性表述（"为了让"、"使…成立"、"结论成立"之类）——把最脏的那种
  写法挡在提交前。

剩下的挡不住，只能靠上面四次自问。
